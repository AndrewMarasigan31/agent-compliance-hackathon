## Codebase Patterns
- Dashboard state uses `UploadResult` interface defined locally in page.tsx (not in types/index.ts)
- Build command: `npm run build` in beat-planner/ runs both typecheck and compilation
- Types in beat-planner/types/index.ts are shared across components and API routes
- BeatResult is the core domain type — extended with assignedAgent for multi-agent support
- DayAssignments type: `{ [agentName: string]: { [beatId: number]: string } }` is the shape for multi-agent scheduling
