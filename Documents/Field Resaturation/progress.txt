## Codebase Patterns
- Next.js 14 App Router with TypeScript and Tailwind CSS
- iron-session for cookie-based auth (PLANNER_PASSWORD env var)
- ml-kmeans for KMeans clustering
- papaparse for CSV parsing
- Leaflet.js for interactive maps
- KML generation via string templates (XML-escaped output)
- All store data is session-only — no database, no persistence
